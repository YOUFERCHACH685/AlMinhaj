ربط الموقع بقاعدة Firebase

عندما يستعمل المشرف والمترشحون هواتف مختلفة، لا تكفي الذاكرة المحلية للمتصفح. اربط الموقع بقاعدة Firebase Realtime Database المجانية مرة واحدة، وستظهر الجلسة وقائمة الانتظار والنتائج لكل الأجهزة فورًا.

ما تحتاجه: حساب Google (مجاني) + 5 دقائق. لا تحتاج إلى بطاقة بنكية.
  1. افتح console.firebase.google.com وسجّل الدخول بحساب Google.
  2. اضغط Add project / «إضافة مشروع»، اختر اسمًا مثل manhaj-exam، ثم Continue. يمكنك تعطيل Google Analytics ثم Create project.
  3. من القائمة الجانبية: Build ← Realtime Database ← Create Database.
  4. اختر موقعًا قريبًا (مثل europe-west1) ← Next ← اختر Start in test mode ← Enable.
  5. انسخ رابط قاعدة البيانات الظاهر أعلى الصفحة. يبدأ بـ https://...firebaseio.com أو https://...firebasedatabase.app.
  6. افتح فضاء المشرف ← تبويب «الإعدادات» ← قسم «المزامنة بين الأجهزة»، الصق الرابط ثم اضغط «حفظ الرابط».
  7. بعد إعادة التحميل، اضغط «نسخ رابط المترشحين». انسخ الرابط الذي يبدأ بـ index.html?db=... ووزّعه على المترشحين (واتساب، رمز QR، ...). هذا الرابط هو الذي يفعّل المزامنة على هواتفهم.
  8. اختبر من هاتفين: أنشئ جلسة من هاتف المشرف، ثم افتح رابط المترشحين على الهاتف الآخر وسجّل اسمًا. يجب أن يظهر المترشح في قائمة الانتظار عند المشرف.
تنبيه أمني: وضع Test mode يسمح لأي شخص يملك الرابط بقراءة البيانات وكتابتها. استعمله للاختبار الداخلي فقط، وأوقف القاعدة أو غيّر القواعد بعد انتهاء الاختبار. لا تضع بيانات شخصية حساسة.

إذا لم تعمل المزامنة

  • تأكد أن الرابط يبدأ بـ https:// وأنه بلا شرطة / في آخره.
  • تأكد أن قاعدة البيانات أُنشئت فعلاً (وليس Firestore فقط).
  • افتح رابط المترشحين الذي يحوي ?db=، وليس الرابط العادي.
  • إذا كانت القاعدة جديدة، انتظر دقيقة بعد إنشائها ثم أعد المحاولة.
  • افتح وحدة تحكم المتصفح (F12) وتحقق من رسائل الخطأ.
